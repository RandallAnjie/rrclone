# 115 Drive

[115 Drive](https://115.com) (115 网盘) is a Chinese cloud storage
provider. This backend uses the **115 web API** (`webapi.115.com`)
with the cookies from a logged-in browser session.

It does **not** use 115 OpenAPI. 115 has deprecated that interface.

## Configuration

Log in to [115.com](https://115.com) in a browser, then copy these
cookies from DevTools → Application → Cookies:

- `UID`
- `CID`
- `SEID`
- `KID` (present on newer sessions)

You can paste them as one cookie string:

```text
UID=...; CID=...; SEID=...; KID=...
```

Here is an example of how to make a remote called `remote`. First run:

```console
rclone config
```

```text
No remotes found, make a new one?
n) New remote
s) Set configuration password
q) Quit config
n/s/q> n
name> remote
Option Storage.
Type of storage to configure.
Choose a number from below, or type in your own value.
XX / 115 Drive
   \ (115)
Storage> 115
Option cookie.
115 web cookie string.
Enter a value. Press Enter to leave empty.
cookie> UID=...; CID=...; SEID=...; KID=...
Edit advanced config?
y) Yes
n) No (default)
y/n> n
y) Yes this is OK (default)
e) Edit this remote
d) Delete this remote
y/e/d> y
```

Once configured you can then use `rclone` like this (replace `remote`
with the name you gave your remote):

List directories and files in the top level of your 115 Drive

```console
rclone lsf remote:
```

To copy a local directory to a 115 directory called backup

```console
rclone copy /home/source remote:backup
```

Cookies expire. If rclone starts returning login errors, copy a fresh
cookie string from the browser and update the remote with
`rclone config update remote cookie "UID=...; CID=...; SEID=...; KID=..."`.

### Modification times and hashes

115 Drive does not allow rclone to set modification times, so they
will not be preserved when copying to 115.

115 Drive supports SHA-1 hashes, so you can use the `--checksum` flag.

### Restricted filename characters

In addition to the [default restricted characters set](/overview/#restricted-characters)
the following characters are also replaced:

| Character | Value | Replacement |
| --------- |:-----:|:-----------:|
| *         | 0x2A  | ＊           |
| :         | 0x3A  | ：           |
| <         | 0x3C  | ＜           |
| >         | 0x3E  | ＞           |
| ?         | 0x3F  | ？           |
| "         | 0x22  | ＂           |
| \         | 0x5C  | ＼           |
| \|        | 0x7C  | ｜           |

Invalid UTF-8 bytes will also be [replaced](/overview/#invalid-utf8).

### Root folder ID

You can set `root_folder_id` to a 115 directory CID to restrict rclone
to that folder. Leave it blank to use the account root.

### Standard options

Here are the Standard options specific to 115 (115 Drive).

#### --115-cookie

115 web cookie string.

Copy UID, CID, SEID and KID from the browser after logging in to
https://115.com (DevTools → Application → Cookies). A single string
like "UID=...; CID=...; SEID=...; KID=..." is enough.

This backend talks to the 115 web API (webapi.115.com). Do not use
115 OpenAPI tokens; that API is deprecated.


Properties:

- Config:      cookie

- Type:        string

## Limitations

- Empty files cannot be uploaded.
- Cookies are session credentials. Treat them like a password and do
  not share the config file.
- 115 returns `errno 990001` / "登录超时" when the cookie is stale,
  when another login on the same app slot (the `A1` in `UID=..._A1_...`
  is the web/desktop slot) kicked this session, or when 115 rejects the
  client IP. Copy `UID`/`CID`/`SEID`/`KID` as **one line** from DevTools
  after a fresh login.
- 115 rate-limits aggressive listing and uploading. If you see HTTP
  403 or errno 990009, lower `--transfers` (5 is a reasonable start)
  and `--checkers`.
- Very large uploads go through 115's Aliyun OSS endpoint after a SHA-1
  rapid-upload check. Rapid upload (秒传) is used when 115 already has
  the file content.
- This backend is implemented against the web/app APIs. Behaviour can
  change if 115 updates those endpoints.
