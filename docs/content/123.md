# 123 Cloud

[123 Cloud](https://www.123pan.com) (123 云盘) is a Chinese cloud
storage provider. This backend uses the **123 Open Platform API**
(`open-api.123pan.com`).

Apply for `client_id` and `client_secret` at
[123pan.com/developer](https://www.123pan.com/developer). rclone
exchanges those credentials for an access token. Do not use a
third-party token broker.

## Configuration

Here is an example of how to make a remote called `remote`. First run:

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> 123
client_id> YOUR_CLIENT_ID
client_secret> YOUR_CLIENT_SECRET
```

List files:

```console
rclone lsf remote:
```

Copy a local directory:

```console
rclone copy /home/source remote:backup
```

### Modification times and hashes

123 Cloud returns modification times with 1 second precision. rclone
cannot set them.

123 Cloud supports MD5 (etag) and SHA-1. SHA-1 is used for hash
reuse on upload when the source provides it.

### Standard options

#### --123-client_id

123 Open Platform client ID.

#### --123-client_secret

123 Open Platform client secret.

### Advanced options

#### --123-access_token

Access token. Optional if client credentials are set.

#### --123-root_folder_id

ID of the root folder. Leave blank to use the account root.

#### --123-endpoint

Endpoint for the 123 Open Platform API. Default `https://open-api.123pan.com`.
