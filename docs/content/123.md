# 123 Cloud

[123 Cloud](https://www.123pan.com) (123 云盘) is a Chinese cloud
storage provider.

The easy path is **username and password** (the same login as
yun.123pan.com). rclone talks to the web API and stores the token in
`access_token`.

The Open Platform API (`open-api.123pan.com`) is still available:
set `client_id` and `client_secret` from
[123pan.com/developer](https://www.123pan.com/developer) and omit
`user`/`pass`. Do not use a third-party token broker.

## Configuration

Here is an example of how to make a remote called `remote`. First run:

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> 123
user> YOUR_PHONE_OR_EMAIL
pass> YOUR_PASSWORD
```

List files:

```console
rclone lsf remote:
```

Copy a local directory:

```console
rclone copy /home/source remote:backup
```

### Modification times and hashes

123 Cloud returns modification times with 1 second precision. rclone
cannot set them.

123 Cloud supports MD5 (etag) and SHA-1. SHA-1 is used for hash
reuse on upload when the source provides it.

### Standard options

#### --123-user

123 Cloud username (phone number or email).

#### --123-pass

123 Cloud password.

### Advanced options

#### --123-client_id

123 Open Platform client ID. Optional if user/pass are set.

#### --123-client_secret

123 Open Platform client secret.

#### --123-access_token

Access token. Filled after web login, or optional if Open Platform
credentials are set.

#### --123-root_folder_id

ID of the root folder. Leave blank to use the account root.

#### --123-endpoint

Endpoint for the 123 API. Web login defaults to
`https://www.123pan.com`. Open Platform default is
`https://open-api.123pan.com`.

#### --123-login_endpoint

Endpoint for unofficial web login. Default
`https://login.123pan.com/api`.

## Direct download links

`rclone link remote:path/to/file` returns a time-limited CDN URL
(直链). Directories cannot be linked. `--unlink` is not supported.
