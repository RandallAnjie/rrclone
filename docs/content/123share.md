# 123 Share

[123 Share](https://www.123pan.com) 123 Cloud public share. share_key from the share URL.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> 123share
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

123 Cloud public share. share_key from the share URL.

### Standard options

#### --123share-share_key

Share key or share id.
#### --123share-share_pwd

Share password, if any.
