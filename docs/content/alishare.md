# Aliyun Drive Share

[Aliyun Drive Share](https://www.alipan.com) Aliyun Drive share. share_key is share_id.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> alishare
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Aliyun Drive share. share_key is share_id.

### Standard options

#### --alishare-share_key

Share key or share id.
#### --alishare-share_pwd

Share password, if any.
