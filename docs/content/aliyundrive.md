# Aliyun Drive

[Aliyun Drive](https://www.alipan.com) (阿里云盘) is a Chinese cloud
drive. This backend uses its official **open platform API**
(`openapi.alipan.com`).

## Configuration

You need an app on the
[Aliyun Drive open platform](https://www.alipan.com/developer). Note its
App ID and App Secret.

```console
rclone config
```

```text
n) New remote
name> remote
Storage> aliyundrive
client_id> your App ID
client_secret> *** (y to type it)
drive_type> default
Open this page, log in and allow rclone, then paste the code it shows:

https://openapi.alipan.com/oauth/authorize?...
config_code> 1a2b3c...
```

Open the page, log in, allow the app and paste the code it shows. If
you already have a refresh token for the app, set `refresh_token`
instead (advanced options) and rclone uses it.

Aliyun Drive gives a new refresh token on every refresh. rclone saves
it to the config, so keep the config writable.

`drive_type` picks the drive: `default` (备份盘) or `resource`
(资源库).

## Hashes and modification times

Aliyun Drive keeps a SHA1 of every file, which rclone uses for checks.
It sets modification times itself, so rclone compares sizes, and SHA1s
with `--checksum`.

## Uploads and updates

Files are uploaded in parts (20 MiB, larger for very big files). An
updated file is uploaded beside the old one, which is removed once the
upload has finished, so a failed update leaves the old file.

## Server-side operations

Moves, renames, directory moves and copies are done by Aliyun Drive.
Copies within one folder aren't supported, so rclone downloads and
uploads instead. The same goes for a copy onto an existing file,
because Aliyun Drive's copy can't replace one and would leave two files
of the same name.

## Rate limits

The open platform allows about 4 listings, 1 download link and 15 other
requests a second. rclone keeps to these limits, so opening many files
is slow.

## Limitations

- Deleted files go to the recycle bin unless `hard_delete` is set.
- Aliyun Drive allows two files with the same name in one folder.
  rclone sees the first one.
- Modification times can't be set.
- Use of the open platform may need a paid quota pack for third party
  apps.
