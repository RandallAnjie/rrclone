# Baidu Netdisk

[Baidu Netdisk](https://pan.baidu.com) (百度网盘) is a Chinese cloud
drive. This backend uses its official **open platform (xpan) API**.

## Configuration

You need an app on the [Baidu open platform](https://pan.baidu.com/union):

1. Create an app and note its **AppKey** (client ID) and **SecretKey**
   (client secret).
2. Add `http://localhost:53682/` as its OAuth redirect URL.

```console
rclone config
```

```text
n) New remote
name> remote
Storage> baidu
client_id> your AppKey
client_secret> your SecretKey
Use web browser to automatically authenticate rclone with remote?
y/n> y
```

Log in to Baidu in the browser and allow the app. rclone keeps the
token in the config and refreshes it.

```console
rclone lsd remote:
```

Some apps may only use their own folder. Then set `root_folder` to
`/apps/<app name>`.

## Modification times and hashes

rclone stores the modification time with each upload and reads it back,
with one second precision. It can't be changed afterwards without
uploading again.

Baidu's `md5` field isn't reliably the MD5 of the content, so rclone
doesn't offer hashes and compares sizes and times.

## Uploads

Baidu needs the MD5 of every block of a file before the upload starts,
so rclone copies each upload to a temporary file first. This also lets
rclone upload streams of unknown size, such as `rclone rcat`.

When Baidu already has the same content, the upload completes without
sending the data. Blocks are 4 MiB, 16 MiB for VIP and 32 MiB for SVIP
members (rclone reads the membership), or `block_size`.

## Server-side operations

Copies, moves and renames are done by Baidu, including a rename in the
same request as a copy or move.

## Reverse proxies

If Baidu's hosts are blocked, point `api_url` (pan.baidu.com),
`upload_url` (d.pcs.baidu.com) and `oauth_url` (openapi.baidu.com) at
reverse proxies of them.

## Limitations

- Deleted files go to the Baidu recycle bin.
- Downloads are speed limited for members without VIP.
- Names can't contain `\ ? | " > < : *` or start or end with white
  space. rclone encodes these characters, see
  [encoding](/overview/#encoding).
- Baidu limits how often the API may be called. rclone waits and
  retries when told to slow down.
