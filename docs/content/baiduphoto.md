# Baidu Photos

[Baidu Photos](https://photo.baidu.com) Baidu Photos / 一刻相册.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> baiduphoto
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

#### --baiduphoto-token
