# Chaoxing

[Chaoxing](https://www.chaoxing.com) Chaoxing group drive. Cookie from chaoxing.com.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> chaoxing
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Chaoxing group drive. Cookie from chaoxing.com.

### Standard options

#### --chaoxing-cookie

Chaoxing cookie string.
