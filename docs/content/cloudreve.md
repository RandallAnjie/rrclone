# Cloudreve

[Cloudreve](https://cloudreve.org) Self-hosted Cloudreve v3. Cookie from your own site.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> cloudreve
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Self-hosted Cloudreve v3. Cookie from your own site.

### Standard options

#### --cloudreve-cookie

Cloudreve cookie string.
