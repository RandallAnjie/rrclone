# Cloudreve V4

[Cloudreve V4](https://cloudreve.org) Self-hosted Cloudreve v4.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> cloudrevev4
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Self-hosted Cloudreve v4.

### Standard options

#### --cloudrevev4-token

Cloudreve V4 API token.
