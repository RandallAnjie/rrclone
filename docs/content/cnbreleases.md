# CNB Releases

[CNB Releases](https://cnb.cool) CNB (cnb.cool) release assets.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> cnbreleases
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

CNB (cnb.cool) release assets.

### Standard options

#### --cnbreleases-token

CNB Releases API token.
