# Doubao

[Doubao](https://www.doubao.com) Doubao files. Cookie from www.doubao.com.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> doubao
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Doubao files. Cookie from www.doubao.com.

### Standard options

#### --doubao-cookie

Doubao cookie string.
