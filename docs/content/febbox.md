# FebBox

[FebBox](https://www.febbox.com) FebBox. Token from OAuth.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> febbox
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

FebBox. Token from OAuth.

### Standard options

#### --febbox-token

FebBox API token.
