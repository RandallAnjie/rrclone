# HalalCloud

[HalalCloud](https://www.halalcloud.com) HalalCloud. Token is a refresh_token from the official client.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> halalcloud
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

HalalCloud. Token is a refresh_token from the official client.

### Standard options

#### --halalcloud-token

HalalCloud API token.
