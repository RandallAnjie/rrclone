# Cloudflare ImgBed

[Cloudflare ImgBed](https://github.com/MarSeventh/CloudFlare-ImgBed) Cloudflare ImgBed. Token is the manage auth.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> imgbed
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Cloudflare ImgBed. Token is the manage auth.

### Standard options

#### --imgbed-token

Cloudflare ImgBed API token.
