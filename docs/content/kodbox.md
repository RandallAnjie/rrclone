# KodBox

[KodBox](https://kodcloud.com) KodBox / KodExplorer. Username and password for your own site.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> kodbox
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

KodBox / KodExplorer. Username and password for your own site.

### Standard options

#### --kodbox-username

Account username.
#### --kodbox-password

Account password.
