# MediaFire

[MediaFire](https://www.mediafire.com) MediaFire. Cookie from a logged-in www.mediafire.com session.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> mediafire
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

MediaFire. Cookie from a logged-in www.mediafire.com session.

### Standard options

#### --mediafire-cookie

MediaFire cookie string.
