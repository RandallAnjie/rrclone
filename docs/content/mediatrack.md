# MediaTrack

[MediaTrack](https://www.mediatrack.cn) MediaTrack DAM.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> mediatrack
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

MediaTrack DAM.

### Standard options

#### --mediatrack-token

MediaTrack API token.
