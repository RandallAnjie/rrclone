# MoPan

[MoPan](https://mopan.com) China Mobile MoPan. Username (phone) and password.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> mopan
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

China Mobile MoPan. Username (phone) and password.

### Standard options

#### --mopan-username

Account username.
#### --mopan-password

Account password.
