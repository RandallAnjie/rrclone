# Teambition

[Teambition](https://www.teambition.com) Teambition project files. Cookie from a logged-in session.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> teambition
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Teambition project files. Cookie from a logged-in session.

### Standard options

#### --teambition-cookie

Teambition cookie string.
