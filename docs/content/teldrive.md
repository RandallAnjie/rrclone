# Teldrive

[Teldrive](https://github.com/tgdrive/teldrive) Teldrive. Cookie must contain access_token=.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> teldrive
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Teldrive. Cookie must contain access_token=.

### Standard options

#### --teldrive-cookie

Teldrive cookie string.
