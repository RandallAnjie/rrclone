# Thunder Drive

[Thunder Drive](https://pan.xunlei.com) Xunlei Thunder Drive. Username and password. Captcha may be required on some accounts.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> thunder
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Xunlei Thunder Drive. Username and password. Captcha may be required on some accounts.

### Standard options

#### --thunder-username

Account username.
#### --thunder-password

Account password.
