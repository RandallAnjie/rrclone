# ThunderX

[ThunderX](https://www.xunlei.com) Xunlei ThunderX. Same API as Thunder with a different host.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> thunderx
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Xunlei ThunderX. Same API as Thunder with a different host.

### Standard options

#### --thunderx-username

Account username.
#### --thunderx-password

Account password.
