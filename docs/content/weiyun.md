# WeiYun

[WeiYun](https://www.weiyun.com) Tencent WeiYun. Cookie from www.weiyun.com.

## Configuration

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> weiyun
```

```console
rclone lsf remote:
```

Do not use a third-party token broker.

Tencent WeiYun. Cookie from www.weiyun.com.

### Standard options

#### --weiyun-cookie

WeiYun cookie string.
