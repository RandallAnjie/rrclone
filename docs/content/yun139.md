# China Mobile Yun 139

[Yun 139](https://yun.139.com) (和彩云 / 中国移动云盘) is China
Mobile's consumer cloud storage. This backend uses the **Yun 139 web
API** (`yun.139.com`) with the Authorization header from a logged-in
browser session.

## Configuration

Log in to [yun.139.com](https://yun.139.com) and copy:

- the `Authorization` request header
- the account (usually the phone number)

```console
rclone config
```

```text
n/s/q> n
name> remote
Storage> yun139
authorization> Basic ...
account> 13800000000
```

```console
rclone lsf remote:
```

The Authorization header expires. Copy a fresh value if rclone
starts returning login errors.

### Modification times and hashes

Yun 139 returns modification times and an MD5 digest when the API
provides one. rclone cannot set modification times.

### Standard options

#### --yun139-authorization

Authorization header from a logged-in yun.139.com session.

#### --yun139-account

Account name, usually the phone number.

### Advanced options

#### --yun139-root_folder_id

ID of the root catalog. Leave blank to use the account root.

#### --yun139-endpoint

Endpoint for the Yun 139 API. Default `https://yun.139.com`.
